Time Series Forecasting with Prophet and LSTM

#data-science #time-series #deep-learning #prophet

Time series forecasting is everywhere - stock prices, sales predictions, server load forecasting. I've built models for all of these, and the two approaches that consistently work are Facebook's Prophet and LSTM networks. Let me show you when to use each.

Prophet: The Quick Win

Prophet is my go-to for business forecasting. It's fast, handles missing data, and works out of the box:

from prophet import Prophet
import pandas as pd

# Prophet needs 'ds' (date) and 'y' (value) columns
df = pd.DataFrame({
    'ds': dates,
    'y': sales_values
})

model = Prophet(
    yearly_seasonality=True,
    weekly_seasonality=True,
    daily_seasonality=False
)

model.fit(df)

# Forecast 90 days ahead
future = model.make_future_dataframe(periods=90)
forecast = model.predict(future)

# Plot results
model.plot(forecast)
model.plot_components(forecast)

The component plots are gold - they show you trends, seasonality, and holidays separately. This helped me explain to stakeholders why sales dip every January.

# Add monthly seasonality

holidays = pd.DataFrame({

    'lower_window': -1,
    'upper_window': 1,
})

model = Prophet(holidays=holidays)

LSTM: When You Need More Power

LSTMs shine when you have complex patterns and lots of data. Here's a basic implementation:

import numpy as np
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense, Dropout

def create_sequences(data, seq_length):
    X, y = [], []
    for i in range(len(data) - seq_length):
        X.append(data[i:i+seq_length])
        y.append(data[i+seq_length])
    return np.array(X), np.array(y)

# Prepare data
seq_length = 60  # Use 60 days to predict next day
X, y = create_sequences(scaled_data, seq_length)

# Reshape for LSTM [samples, timesteps, features]
X = X.reshape((X.shape[0], X.shape[1], 1))

# Build model
model = Sequential([
    LSTM(50, return_sequences=True, input_shape=(seq_length, 1)),
    Dropout(0.2),
    LSTM(50, return_sequences=False),
    Dropout(0.2),
    Dense(25),
    Dense(1)
])

model.compile(optimizer='adam', loss='mse')
model.fit(X, y, epochs=50, batch_size=32, validation_split=0.2)

Prophet vs LSTM: When to Use What

Use Prophet when:

  • You have clear seasonality patterns
  • You need quick results
  • You want interpretable forecasts
  • You have missing data or outliers

Use LSTM when:

  • You have lots of training data (1000+ points)
  • Patterns are complex and non-linear
  • You need to capture long-term dependencies
  • You have multiple input features

Real-World Example: Sales Forecasting

I built both models for a retail client. Prophet gave 85% accuracy with 2 hours of work. LSTM took 2 days of tuning but reached 91% accuracy. The extra 6% was worth it for their $10M inventory decisions.

Common Pitfalls

1. Not scaling data for LSTM: Always normalize to [0,1] range.

2. Ignoring stationarity: Differencing can help both models.

3. Overfitting LSTM: Use dropout and early stopping.

4. Not validating properly: Use time-based splits, not random splits!

Final Thoughts

Start with Prophet. If you need better accuracy and have the data, try LSTM. And remember - no model can predict black swan events. Always have a plan B.
