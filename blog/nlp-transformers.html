Natural Language Processing with Transformers

#data-science #nlp #transformers #deep-learning

Transformers revolutionized NLP. Before them, we struggled with RNNs and LSTMs. Now? BERT, GPT, and their variants solve problems I thought were impossible. Let me show you how to use them effectively.

Why Transformers Changed Everything

The attention mechanism is genius. Instead of processing text sequentially, transformers look at all words simultaneously and learn which words are important for understanding context. This parallel processing makes them both faster and more accurate.

Getting Started with Hugging Face

Hugging Face's transformers library makes using these models trivial:

from transformers import pipeline

# Sentiment analysis
classifier = pipeline("sentiment-analysis")
result = classifier("I love this product!")
# [{'label': 'POSITIVE', 'score': 0.9998}]

# Named Entity Recognition
ner = pipeline("ner", grouped_entities=True)
result = ner("Apple Inc. is located in Cupertino, California")

# Question Answering
qa = pipeline("question-answering")
context = "The Eiffel Tower is in Paris, France."
question = "Where is the Eiffel Tower?"
result = qa(question=question, context=context)

That's it. Three lines of code for state-of-the-art NLP. Mind-blowing.

Fine-Tuning BERT for Classification

Pre-trained models are great, but fine-tuning on your data makes them exceptional:

from transformers import BertTokenizer, BertForSequenceClassification
from transformers import Trainer, TrainingArguments
import torch

# Load pre-trained model
model = BertForSequenceClassification.from_pretrained(
    'bert-base-uncased',
    num_labels=2
)
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')

# Tokenize data
def tokenize_function(examples):
    return tokenizer(
        examples['text'],
        padding='max_length',
        truncation=True,
        max_length=512
    )

tokenized_datasets = dataset.map(tokenize_function, batched=True)

# Training arguments
training_args = TrainingArguments(
    output_dir='./results',
    num_train_epochs=3,
    per_device_train_batch_size=16,
    per_device_eval_batch_size=64,
    warmup_steps=500,
    weight_decay=0.01,
    logging_dir='./logs',
)

# Train
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_datasets['train'],
    eval_dataset=tokenized_datasets['test']
)

trainer.train()

I fine-tuned BERT on customer reviews and got 94% accuracy. The pre-trained model alone was at 78%. Fine-tuning is worth it.

Text Generation with GPT

from transformers import GPT2LMHeadModel, GPT2Tokenizer

tokenizer = GPT2Tokenizer.from_pretrained('gpt2')
model = GPT2LMHeadModel.from_pretrained('gpt2')

# Generate text
input_text = "The future of AI is"
input_ids = tokenizer.encode(input_text, return_tensors='pt')

output = model.generate(
    input_ids,
    max_length=100,
    num_return_sequences=1,
    temperature=0.7,
    top_k=50,
    top_p=0.95,
    do_sample=True
)

generated_text = tokenizer.decode(output[0], skip_special_tokens=True)

Temperature controls randomness - lower is more focused, higher is more creative. I use 0.7 for most tasks.

Practical Tips

1. Start with smaller models: distilbert is 40% smaller and 60% faster than BERT, with 97% of the performance.

2. Use mixed precision training: Cuts training time in half on modern GPUs.

3. Batch your predictions: Processing 100 texts at once is 10x faster than one at a time.

4. Cache tokenized data: Tokenization is slow. Do it once, save it.

Real-World Application: Customer Support

I built a system that automatically categorizes support tickets:

# Load fine-tuned model
model = BertForSequenceClassification.from_pretrained('./my-model')
tokenizer = BertTokenizer.from_pretrained('./my-model')

def categorize_ticket(text):
    inputs = tokenizer(text, return_tensors='pt', truncation=True)
    outputs = model(**inputs)
    prediction = torch.argmax(outputs.logits, dim=1)
    
    categories = ['billing', 'technical', 'general']
    return categories[prediction.item()]

# Use it
ticket = "I can't log into my account"
category = categorize_ticket(ticket)  # Returns: 'technical'

This reduced response time by 40% by routing tickets to the right team immediately.

Common Mistakes

1. Not truncating long texts: BERT has a 512 token limit. Longer texts get cut off.

2. Forgetting to set model.eval(): Always use eval mode for inference.

3. Not using GPU: These models are slow on CPU. Use GPU or cloud services.

Final Thoughts

Transformers made NLP accessible. You don't need a PhD to build production-quality NLP systems anymore. Start with pre-trained models, fine-tune on your data, and iterate.

The future of NLP is here, and it's transformers all the way down.
