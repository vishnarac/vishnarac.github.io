Exploratory Data Analysis: A Practical Guide

#data-science #python #eda #visualization

EDA is where data science actually happens. Not in fancy models, but in understanding your data. I've seen teams waste weeks building models on data they didn't understand. Don't be that team.

Start with the Basics

Always start here:

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# Load data
df = pd.read_csv('data.csv')

# First look
print(df.head())
print(df.info())
print(df.describe())

# Check for missing values
print(df.isnull().sum())

# Check data types
print(df.dtypes)

This takes 30 seconds and tells you 80% of what you need to know.

Visualizing Distributions

# Numerical features
df.hist(figsize=(15, 10), bins=50)
plt.tight_layout()
plt.show()

# Or use seaborn for prettier plots
for col in df.select_dtypes(include=[np.number]).columns:
    plt.figure(figsize=(10, 4))
    sns.histplot(df[col], kde=True)
    plt.title(f'Distribution of {col}')
    plt.show()

# Box plots for outliers
plt.figure(figsize=(12, 6))
df.boxplot()
plt.xticks(rotation=45)
plt.show()

Correlation Analysis

# Correlation matrix
corr = df.corr()

# Heatmap
plt.figure(figsize=(12, 10))
sns.heatmap(corr, annot=True, cmap='coolwarm', center=0)
plt.title('Correlation Matrix')
plt.show()

# Find highly correlated features
high_corr = corr[abs(corr) > 0.8]
print(high_corr)

I once found two features with 0.99 correlation. Turned out they were the same thing measured differently. Removing one improved model performance.

Categorical Variables

# Value counts
for col in df.select_dtypes(include=['object']).columns:
    print(f"\n{col}:")
    print(df[col].value_counts())

# Bar plots
fig, axes = plt.subplots(2, 2, figsize=(15, 10))
for idx, col in enumerate(df.select_dtypes(include=['object']).columns[:4]):
    df[col].value_counts().plot(kind='bar', ax=axes[idx//2, idx%2])
    axes[idx//2, idx%2].set_title(col)
plt.tight_layout()
plt.show()

Handling Outliers

# IQR method
Q1 = df.quantile(0.25)
Q3 = df.quantile(0.75)
IQR = Q3 - Q1

# Find outliers
outliers = ((df < (Q1 - 1.5 * IQR)) | (df > (Q3 + 1.5 * IQR))).sum()
print("Outliers per column:")
print(outliers)

# Visualize with box plots
sns.boxplot(data=df)
plt.xticks(rotation=45)
plt.show()

Don't automatically remove outliers. Sometimes they're the most interesting data points.

Time Series Analysis

if 'date' in df.columns:
    df['date'] = pd.to_datetime(df['date'])
    df.set_index('date', inplace=True)
    
    # Plot over time
    df['value'].plot(figsize=(15, 5))
    plt.title('Value over Time')
    plt.show()
    
    # Resample to monthly
    monthly = df.resample('M').mean()
    monthly.plot(figsize=(15, 5))
    plt.title('Monthly Average')
    plt.show()

My EDA Checklist

  • ✓ Load data and check shape
  • ✓ Check data types and missing values
  • ✓ Get summary statistics
  • ✓ Visualize distributions
  • ✓ Check for outliers
  • ✓ Analyze correlations
  • ✓ Explore categorical variables
  • ✓ Look for patterns over time
  • ✓ Document findings

Tools That Make EDA Easier

# pandas-profiling: Automatic EDA report
from pandas_profiling import ProfileReport

profile = ProfileReport(df, title="EDA Report")
profile.to_file("report.html")

# sweetviz: Compare datasets
import sweetviz as sv

report = sv.analyze(df)
report.show_html("sweetviz_report.html")

These tools generate comprehensive reports in seconds. Use them for initial exploration, then dig deeper manually.

The EDA That Saved a Project

Last year, a client's model had terrible accuracy. During EDA, I found that 40% of their "customer age" values were over 150 years old. Data entry error. Fixed the data, retrained the model, accuracy jumped from 65% to 89%.

EDA isn't glamorous, but it's where the real work happens. Spend time here. Your models will thank you.
